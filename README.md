# New Moon Tattoo

Site de apresentação do estúdio New Moon Tattoo. A página reúne trabalhos de tatuagem, informações sobre o atendimento e formas de entrar em contato.

## Sobre o site

- **Página inicial:** apresenta o estúdio e uma galeria de tatuagens. Clique em uma imagem para ampliá-la; feche a visualização clicando fora dela, no botão de fechar ou pressionando `Esc`.
- **Sobre:** conta um pouco sobre a proposta e o trabalho da New Moon.
- **Localização e contato:** exibe um mapa de Duque de Caxias, no Rio de Janeiro, e oferece contato pelo WhatsApp.
- **Layout responsivo:** adapta os elementos da página para telas menores.

## Tecnologias

HTML, CSS e JavaScript, sem dependências ou etapa de compilação.

## Como visualizar

Abra o arquivo `index.html` em um navegador. Para acessar a página Sobre, use o link no menu da página inicial.
